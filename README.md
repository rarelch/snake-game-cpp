# Snake Game
> Undergraduate Course Design: Classic Snake Game based on C++
> 本科课程设计：基于C++实现经典贪吃蛇小游戏

## Project Introduction 项目简介
This is a classic snake game developed as an undergraduate course design, implemented in C++ with Visual Studio.
The project contains complete VS solution files, source codes and image resources.
Core functions: snake movement, food random generation, collision detection, score counting and game-over judgment.

本项目为本科课程设计作业，使用C++语言在Visual Studio环境开发经典贪吃蛇游戏。
项目包含完整VS工程文件、源代码以及图片素材。
主要功能：蛇身移动、食物随机生成、碰撞检测、分数统计、游戏结束判定。

## Environment 运行环境
- Visual Studio
- C++

## Usage 使用方法
1. Open `SnakeGame.sln` in Visual Studio
2. Build the project and run

1. 使用Visual Studio打开`SnakeGame.sln`
2. 生成项目并运行
